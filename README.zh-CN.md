## 特性

- 90+ 个手工绘制的 SVG 场景与 18 个 GIF 演示
- 自主行为引擎，兼顾安静陪伴、活跃动作与贴边躲藏
- 鼠标眼球跟随、果冻物理、帽子锚点跟随
- 丰富交互：拖拽、悬停反应、点击反应、抚摸与换装
- Linux 桌面集成：通知监听、X11 键盘活动监听、托盘控制与极简模式
- 本地 HTTP API，外加可复用的事件钩子桥接脚本
- 提供英文与简体中文文档

## 快速开始

```bash
git clone https://github.com/zgyk4167/clawd-desktop-pet.git
cd clawd-desktop-pet
npm install
npm start
```

构建 Linux 安装包：

```bash
npm run build:linux
```

## 可选事件钩子

生成或合并一份 JSON 钩子配置文件：

```bash
CLAWD_HOOKS_SETTINGS="$HOME/.config/clawd/hooks.json" node hooks/install.js
```

如果你已经有现成的 JSON 钩子配置，可以把 `CLAWD_HOOKS_SETTINGS` 指向那个文件，安装脚本会把命令安全地合并进去。

## 本地 API

你也可以直接向桌宠发送状态：

```bash
curl -X POST http://127.0.0.1:23333/state \
  -H "Content-Type: application/json" \
  -d '{"state":"working","session_id":"demo","event":"PreToolUse"}'
```

演示时可额外传入 `"svg":"clawd-react-sparkle.svg"` 来强制播放某个动画。

## 工作原理

```text
桌面通知 / 键盘活动 / 外部 hook 事件
  -> hooks/clawd-hook.js 或 src/main.js 中的监听器
  -> 127.0.0.1:23333 本地 HTTP 服务
  -> 状态解析器 + 行为引擎
  -> renderer-rich.js 负责转场、果冻形变、帽子跟随与悬停反馈
```

## 项目结构

```text
src/
  main.js          # 状态机、Linux 集成、托盘与本地 API
  behavior.js      # 自主行为与移动逻辑
  renderer-rich.js # 转场、反应、帽子与果冻物理
  renderer.js      # 桌宠窗口使用的渲染辅助逻辑
  preload.js       # IPC 桥接
  index.html       # DOM 外壳
  styles.css       # 布局与动画样式
hooks/
  clawd-hook.js    # stdin 转 HTTP 的外部 hook 桥接脚本
  install.js       # 合并 hook 命令到 JSON 配置文件
assets/
  svg/             # 像素风 SVG 状态资源
```
