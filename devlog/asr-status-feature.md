# ASR 连接状态提示功能

## 功能说明
在 ASR WebSocket 连接建立之前或重连过程中，向用户显示连接状态提示。

## 修改内容

### 1. main.js - 主进程
- 在 WebSocket `error` 事件中，当首次连接失败时发送 "连接质量差，正在尝试重连..." 状态
- 在 WebSocket `close` 事件中：
  - 发送 "连接已断开，正在重连..." 状态
  - 发送 "正在重连 (X/10)..." 状态，显示重连进度

### 2. preload.js - 预加载脚本
- 添加 `onAsrStatus` IPC 监听器，用于将状态消息传递给渲染进程

### 3. renderer.js - 渲染进程
- 添加 `window.electronAPI.onAsrStatus` 事件监听器
- 连接成功时自动清除状态消息
- 使用 `showAsrStatus()` 函数显示状态信息，5秒后自动隐藏

## 状态消息类型
1. **"连接质量差，正在尝试重连..."** - 首次连接失败时显示
2. **"连接已断开，正在重连..."** - 连接断开时显示
3. **"正在重连 (X/10)..."** - 显示重连尝试次数和最大重连次数

## UI 元素
状态消息显示在 `#asr-status` 元素中，样式为：
- 背景色：rgba(59, 114, 255, 0.3)
- 文字颜色：#6bb5ff
- 字体大小：11px
- 自动居中显示
- 5秒后自动隐藏
