### 4. 左键 Popup 菜单功能开发

#### 4.1 方案设计
- 采用**独立 BrowserWindow** 实现弹窗菜单，而非在 80×80 的宠物窗口内嵌套 DOM
- 独立窗口方案避免了 DOM 布局冲突和透明窗口渲染问题
- 窗口配置：`frame: false`, `transparent: true`, `alwaysOnTop: true`, `resizable: false`, `skipTaskbar: true`, `hasShadow: true`, `focusable: true`, `type: "toolbar"`

#### 4.2 菜单 UI 实现
- 创建 `popup.html` + `popup.js` 独立渲染文件
- 包含 5 个功能菜单项（均带 SVG 图标）：
  - **Evo快捷框** — 快速唤起 Evo 对话
  - **Evo读屏** — 屏幕内容读取
  - **Evo网盘** — 文件管理
  - **录音纪要** — 录音转笔记
  - **截屏提问** — 截图交互
- 底部搜索栏：输入框 + 搜索图标，支持 Enter 发送和 Escape 取消
- 菜单样式采用 CSS 动画淡入效果（`@keyframes menuFadeIn`，0.15s ease-out）

#### 4.3 智能定位算法
- **纵向决策**：优先在宠物上方弹出（`popup.bottom = pet.top − 16px`），若空间不足则改为下方（`popup.top = pet.bottom + 16px`）
- **横向决策**：优先右对齐宠物（`popup.right = pet.right`），若空间不足则改为左对齐（`popup.left = pet.left`）
- 双向边界 clamp 确保弹窗始终位于屏幕工作区内
- 多显示器支持：遍历所有显示器，选择距离宠物窗口中心最近的一个进行定位

#### 4.4 关闭机制
- 三种关闭方式：
  1. 点击外部区域触发 `blur` 事件 → 100ms 延迟后关闭
  2. 再次点击宠物窗口（toggle 行为）
  3. 按下 Escape 键
- `blur` 处理使用 `setTimeout` 延迟 100ms，避免与其他窗口事件冲突

### 7. 修复点击穿透 Bug（严重级别）

#### 7.1 问题描述
用户点击宠物关闭弹窗后，宠物窗口进入**永久穿透状态**，无法再接收鼠标事件。必须移动鼠标到宠物上方才能恢复，有时甚至完全不恢复。

#### 7.2 根因分析
经过代码追踪，发现三层叠加问题：

**问题一 — 关闭路径主动设置穿透模式**
```javascript
// open-menu 的 toggle 分支
destroyPopup();
win.setIgnoreMouseEvents(true, { forward: true });  // ← 错误！
```
关闭弹窗后反而把宠物窗口锁定为点击穿透，后续无任何代码能解除此状态。

**问题二 — 渲染进程 lastIgnore 缓存失效**
弹窗打开时，焦点转移 → 渲染进程触发 `mouseleave` → `setIgnore(true)` → `lastIgnore = true`。
弹窗关闭后 `lastIgnore` 仍为 `true`，下一次 `setIgnore(false)` 只有在 `mousemove` 事件时才会触发（因为需要与 `lastIgnore` 比较决定是否发送 IPC）。用户如果不移动鼠标直接再次点击，永远不会触发恢复。

**问题三 — IPC 通知无监听者**
主进程已发送 `win.webContents.send("popup-closed")` 消息，但 `renderer.js` 中没有对应的 `ipcRenderer.on("popup-closed", ...)` 监听代码，消息直接丢失。

#### 7.3 修复方案
- **集中化修复**：`destroyPopup()` 统一负责关闭后状态恢复
  - 调用 `win.setIgnoreMouseEvents(false)` 恢复完全交互
  - 发送 `win.webContents.send("popup-closed")` 通知渲染进程
- **移除冗余代码**：所有关闭路径（toggle/close-menu/menu-action/blur）不再各自调用 `setIgnoreMouseEvents`
- **渲染进程重置**：监听 `popup-closed` 消息后设置 `lastIgnore = null`，强制下一次鼠标事件重新计算正确状态

#### 7.4 涉及文件
| 文件 | 变更 |
|------|------|
| `src/main.js` | `destroyPopup()` 新增 `setIgnoreMouseEvents(false)` + `webContents.send("popup-closed")`；移除所有 IPC 处理器中的冗余恢复调用 |
| `src/renderer.js` | 新增 `window.electronAPI.onPopupClosed(() => { lastIgnore = null; })` |
| `src/preload.js` | 新增 `onPopupClosed` IPC 桥接方法 |
